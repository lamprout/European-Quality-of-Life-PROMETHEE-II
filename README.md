# European-Quality-of-Life-PROMETHEE-II

A multi-criteria decision analysis of Quality of Life across 20 European countries (2014–2023), using Eurostat data, Python, and the PROMETHEE II method.

## The Quality of Life folder above is organized into the following files:
1) **Figures**: Contains visualizations of the results of our analysis.
2) **Previous Analytical Report**: Contains an earlier, more detailed report explaining the PROMETHEE II methodology, the python script and the outputs. This report though was developed using fewer countries and criteria than the current study but is displayed for whoever needs more information based on PROMETHEE II, MCDA methods, weights, preference functions or the indicators of Eurostat.
3) **Python File**: Contains the Python script used for our research.
4) **Results**: Contains 2 Excel workbooks we get as output from the Python script. Modifications have been made inside.
5) **Requirements**: Contains the Python libraries required for the project.
